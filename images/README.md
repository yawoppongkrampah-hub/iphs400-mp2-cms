# Approved images

The release-holder adds approved image files here. `cms publish` copies image files
(`.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`, `.svg`) into the public site as `images/`;
nothing else in this folder is copied. Editors cannot add files here: they write the
caption, alt text and Markdown reference only, e.g. `![Alt text](images/file.jpg)`.

Before adding a real photo, confirm Photo permission (see `CONTEXT.md`).

## Demo illustrations

`demo-illustration-1.svg`, `-2.svg` and `-3.svg` are abstract illustrations drawn
for this class project. They are free to reuse, and they are not photos of any ASA
event. Pages that show them must say so.
